# IROBLEND

**いろを、まぜてみよう。**

好きな色を2〜5色えらび、それぞれ1〜5滴で量を変えながら混ぜられる、無料の色混ぜWebアプリです。PC、スマートフォン、タブレットの画面幅に合わせてレイアウトが変わります。

## 使い方

1. 色のグループを開き、色を2〜5色えらびます。
2. 必要なら各色の滴数を変えます。最初はすべて3滴です。
3. 「まぜる！」を押します。混色アニメーションの後に色と近い色名が表示されます。
4. 混色後も色や滴数を変え、「もういちど まぜる！」で結果を比較できます。

「1滴」は色を混ぜる**相対量**です。実際の絵の具の1滴の体積を表すものではありません。

## 開発

Node.js 24 と npm を使用します。

```sh
npm ci
npm run dev
```

検証と静的ビルド:

```sh
npm test
npm run build
```

`dist/` を静的サイトとして配信できます。ビルド後のアセット参照は相対パスなので、ルート配下とサブパス配下のどちらでも使えます。ログイン、バックエンド、Cookie、分析SDK、外部API通信はありません。

## 混色の考え方

[Spectral.js 3.0.0](https://github.com/rvanwijnen/spectral.js)がsRGBから推定した38波長の分光反射率を使います。各色のKubelka–MunkのK/S値を滴数で加重平均し、反射率に戻してから画面用の色に変換します。色名は、表示色と辞書内の色とのOKLab距離で最も近いものを選び、「○○に近い色」と表示します。

実物の絵の具との完全一致は保証しません。顔料、紙、厚さ、乾燥、照明、画面によって見える色が変わります。この説明はアプリ内の「このアプリの色について」からも確認できます。
