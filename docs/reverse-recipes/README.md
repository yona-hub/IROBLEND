# 逆引き配合の監査と検証

原本の `CODEX_PROMPT.md`（24行）と `IROBLEND_reverse_recipe_spec.md`（528行）をLibrary本文読取で全文確認して実装した。ZIP自体のローカルSHA256照合は、WindowsのLibrary取得機能の制約により未実施。テキスト原本をローカル保存する迂回は行っていない。

## 統合後の構成

材料は `colorPresets.ts`、目標は `namedColors.ts` と `targetCatalog.ts` を参照する。色名やHEXは色の参照データに集約し、目標グループだけを別に管理する。混色は統合された仮想顔料モデルで通常の自由混色と逆引き候補を共通計算する。
スマホ操作バーは1280px未満で固定し、safe-areaと本文末尾の余白を確保した。完成後の探索画面は目標と実際の結果を同じ大きさで比較し、完成キャンバスの重複表示を畳む。飛沫の配置とリサイズは統合した `paintGeometry.ts` を使う。

## 実計算の成果

詳細は [audit.html](audit.html) と [audit.json](audit.json)。

- 材料54色、目標125項目。材料にない目標71項目。
- 2色27,189件、3色2,852,460件を全正規比率で評価。各1〜5の整数、同じ材料IDなし。
- 目標と同一ID・同一HEXに加え、目標と同じカテゴリの材料を評価対象から除外。茶・ベージュとグレーには同名の材料カテゴリがなく、カテゴリによる追加除外はない。
- 2〜3色で近さの基準に届かない15目標を4〜5色まで限定探索。55,269件追加。
- 掲載は110目標、322候補。105目標は3件、2目標は2件、3目標は1件。同じ材料で量だけ違う候補や、同じカテゴリ構成で材料だけ入れ替えた候補は掲載しない。オレンジには赤系＋黄系の配合を掲載。
- 掲載先頭候補のΔEOKが0.01以下：88目標、0.02以下：98、0.03以下：103、0.05以下：110。
- 材料にない71目標のうち65目標に掲載候補あり。茶・ベージュ19目標、グレー9目標を含む。
- 15目標は近さの基準を満たす候補がなく掲載しない。「作れない」とは断定しない。対象の詳細は監査JSONを参照。
- 最終生成の所要時間は当該環境で約30秒。環境によって変わる。

## 探索と表示の上限

全2〜3色の時間上限は120秒。10万評価ごとに進捗・最良候補を途中保存し、上限を超えた場合は生成を失敗させる。
4〜5色はbeam幅8、最大4反復、1目標20,000評価／15秒、全体1,000,000評価まで。訪問済み正規比率を除去する。
4〜5色について全体最適は保証しない。スマホで再探索しない。

近さのラベルは、監査と表示確認に基づくアプリ内の方針としてΔEOK 0.02／0.05を採用。同じ6桁HEXの場合だけ「画面上では同じ色」とする。普遍的な知覚保証や「一致率」ではない。
最良候補との差が0.005以内なら材料数の少ない配合を優先。絶対上限0.05は越えない。
候補間では材料IDの集合と材料カテゴリの集合を両方変える。カテゴリ構成ごとの最良配合も探索中に保持し、近さの基準を満たす候補だけを最大3件表示する。
量は正規比率の合法な整数倍からスポイト3本分に近い表現を選び、その表示量で通常の混色関数を再計算して予測色を確定する。

## 整合性と状態

`mixPigmentsColor` は従来関数の数学処理をそのまま共有し、`mixPigments` は色名を付ける既存API。RGB平均・専用補正・混色モデル変更はない。
目標への距離は目標HEXのOKLabと実際の表示結果から求める。`nearestName.deltaE`を使わない。

SHA256のfingerprintはK/Sを定義する顔料ソース、実際の顔料係数、混色・表示補正・色域・丸めのソース、Spectral.jsのバージョン、材料と目標カタログを含む。
ソースは改行を正規化してhash化し、計算由来の係数はJS実行環境の小数末尾の差を避けるためfingerprintに限って12有効桁に揃える。混色に渡す係数は丸めない。
ビルド時と実行時の両方で全掲載候補を通常関数で再計算し、fingerprint・予測HEX・目標色差が不一致なら拒否する。

自由混色と探索実験は別のreducer・marksを持つ。切替で材料・量・結果・dirty・タブ位置を保持。
配合適用は検証済み材料の一括読込でreadyへ移り、前回結果とpendingを消す。混色中はモード・目標・配合の切替を無効にする。
量変更後は前回色と明示し、再混色するまで保存できない。候補閲覧や切替で自動保存しない。
保存は実際に混ぜた材料・量・結果を既存JSON version 2で保存する。任意の目標メタデータは今回追加していない。version 1／2の読込、既存キー、500件、10件ページングは維持。

```sh

```
